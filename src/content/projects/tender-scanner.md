Companies bidding on public tenders in Serbia and Bosnia and Herzegovina track them the hard way: fragmented procurement portals, manual checking, and a real cost to missing the one tender that fits. TenderScanner is my answer to that - a product I design, build and run solo.

The pipeline works end to end in production: scrapers ingest newly published tenders, and a Gemini Flash–based analysis step processes each one so the system can match it against a company's profile and produce a go/no-go recommendation with supporting detail. A React and TypeScript frontend sits on a .NET backend with PostgreSQL underneath.

The product is live and working, with the first interested clients and a feature roadmap ahead - and it doubles as the project where I own every decision, from scraper resilience to what an AI recommendation owes its reader.
